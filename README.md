<p align="center"><img src="https://readme-typing-svg.demolab.com?font=IBM+Plex+Mono&weight=700&size=18&color=8FA3D9&center=true&vCenter=true&width=420&height=40&duration=1&pause=1000000&letterSpacing=6px&lines=OVERVIEW" alt="Overview" /></p>

Planned Rust service to index and query opening trees from Corvin games only. Intended surfaces: an index of finished games by position, a query API for move frequencies and results, and either a standalone HTTP service or embedding into [server](https://github.com/corvin-chess/server). Depends on [chess-core](https://github.com/corvin-chess/chess-core) for rules and position keys. No opening index is in this repository yet.
